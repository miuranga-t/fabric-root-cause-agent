# Investigation Rules V1

Rule 1 - Total Mismatch Check
Compare dashboard total with source total.

Rule 2 - Missing Records Check
Identify records that exist in source but not in dashboard dataset.

Rule 3 - Duplicate Records Check
Identify duplicated transactions.

Rule 4 - Date Range Check
Compare date ranges between dashboard and source.

Rule 5 - Filter Check
Detect filters applied in dashboard but not in source.

Rule 6 - Null Value Check
Detect missing values affecting calculations.

Rule 7 - Refresh Check
Verify dataset refresh date and time.

Rule 8 - Relationship Check
Check for incorrect or inactive relationships.

Rule 9 - Measure Validation Check
Validate DAX calculations.

Rule 10 - Confidence Score
Estimate confidence level of identified root causes.
