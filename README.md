# Fabric Root Cause Agent

Goal:

Build an AI agent that can investigate differences between Power BI dashboards and source data.

Capabilities:

1. Detect sales mismatches
2. Detect missing records
3. Detect duplicate records
4. Detect refresh issues
5. Detect filter mismatches
6. Explain root causes

Future Vision:

An AI Data Analyst Agent capable of investigating business data issues automatically.
